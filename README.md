# Trânsito Fofo

Jogo de navegador para aprender as regras de trânsito brasileiras (CTB), com o bairro do jogo e as ruas de verdade de
Chapecó (SC).

- Jogar: abra `index.html` (no GitHub Pages: o link do site).
- Mapa de Chapecó: © colaboradores do OpenStreetMap (ODbL).
- Feito com Three.js (vendor/three.module.js, licença MIT).
